# Autonomous Driving Perception Stack 🚗

A computer vision-based autonomous driving perception system that detects and tracks objects, identifies road lane markings, and estimates relative depth from video frames.

## 📌 Project Overview

The Autonomous Driving Perception Stack processes driving video using multiple computer vision and deep learning techniques.

The system combines YOLO object detection, ByteTrack object tracking, OpenCV lane detection, and MiDaS monocular depth estimation into an integrated perception pipeline.

The project was implemented using Python and Google Colab.

## 🎯 Project Objectives

- Detect vehicles, pedestrians, buses, and other road objects.
- Track detected objects across video frames.
- Identify lane markings using computer vision.
- Estimate relative depth from camera images.
- Integrate multiple perception modules into one pipeline.
- Evaluate processing speed and export the YOLO model to ONNX.

## ⚙️ System Architecture

The perception pipeline consists of the following modules:

1. **Video Input:** Reads video frames from the input source.
2. **Object Detection:** YOLO identifies objects and generates bounding boxes.
3. **Object Tracking:** ByteTrack assigns tracking IDs to detected objects.
4. **Lane Detection:** OpenCV uses grayscale conversion, Gaussian blur, Canny edge detection, ROI masking, and Hough Line Transform.
5. **Depth Estimation:** MiDaS generates relative depth maps from camera frames.
6. **Integration:** Combines detection, tracking, lane visualization, and depth estimation.
7. **Performance Evaluation:** Measures processing time and FPS.
8. **Model Export:** Exports the YOLO model into ONNX format.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/sparshkum/Autonomous-Driving-Perception-Stack.git

cd Autonomous-Driving-Perception-Stack
```

### 2. Install dependencies

```bash
pip install ultralytics opencv-python-headless
pip install torch torchvision
pip install numpy pandas matplotlib
```

### 3. Open Google Colab

Upload or open the project notebook containing the implementation.

### 4. Load the YOLO model

```python
from ultralytics import YOLO

model = YOLO("yolo11n.pt")
```

### 5. Run the perception pipeline

Execute the object detection, tracking, lane detection, depth estimation, and integration cells.

The final annotated video and performance report are generated by the pipeline.
